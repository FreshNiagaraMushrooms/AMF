# The Mushroom Army Website

A simple, beautiful static website for the Mushroom Army - promoting food recovery, community feeding, and soil regeneration in Niagara.

## What's Inside

- `index.html` - The main webpage with all your content
- `styles.css` - The stylesheet that makes everything look beautiful

## How to Deploy to GitHub Pages

Follow these simple steps to get your website live:

### Step 1: Enable GitHub Pages

1. Go to your repository on GitHub: `https://github.com/FreshNiagaraMushrooms/AMF`
2. Click on **Settings** (top navigation)
3. Scroll down to **Pages** in the left sidebar
4. Under **Source**, select the branch `claude/create-mushroom-page-011CULQ8278Aysqm8sGUphuN`
5. Click **Save**

### Step 2: Wait a Few Minutes

GitHub will build your site. After 1-2 minutes, refresh the Settings page and you'll see a green box with your live URL:

```
Your site is published at https://freshniagaramushrooms.github.io/AMF/
```

That's it! Your website is now live on the internet!

## How to Make Changes

### Editing Content

To change the text on your website:

1. Open `index.html` in any text editor
2. Find the section you want to change (they have helpful comments!)
3. Edit the text between the HTML tags
4. Save the file
5. Commit and push to GitHub
6. GitHub Pages will automatically update in 1-2 minutes

### Changing Colors

To change the colors or styling:

1. Open `styles.css` in any text editor
2. Look for the color codes (like `#5f7a3e` - that's a green color)
3. Change them to your preferred colors
4. You can use a color picker tool online to get color codes
5. Save, commit, and push

### Common Color Codes Used:
- `#5f7a3e` - Dark olive green (primary color)
- `#7d9b5a` - Light sage green (secondary color)
- `#faf9f6` - Warm off-white (background)
- `#2d3748` - Dark charcoal (footer)

## Testing Locally

To preview your changes before pushing to GitHub:

1. Simply open `index.html` in your web browser
2. Right-click the file and select "Open with" → your browser
3. Make changes, save, and refresh the browser to see updates
